# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub: open the **Security** tab of this repository and
choose **Report a vulnerability** (private vulnerability reporting). If that is not
available, contact the maintainer listed in `LICENSE` through their GitHub profile.

Include:

- what is affected (version or commit) and what an attacker gains,
- steps or a minimal input that reproduces it,
- any suggested fix.

## What to expect

- Acknowledgement within 7 days.
- A fix or a written assessment within 90 days.
- Credit in `CHANGELOG.md` if you want it.

## Supported versions

Only the latest release on the default branch receives security fixes.
